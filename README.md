# CodeFactory — Роботтар фабрикасы

Информатика сабағына арналған бөлек браузер ойыны. Оқушы роботты Python кодымен немесе блоктармен басқарады, ал код орындалған сайын фабрикадағы робот экранда қозғалады.

Ашу: `index.html` файлын браузерде аш (сервер керек емес). Vercel-ге статикалық сайт ретінде қосуға болады, баптау керек емес.

## Деңгейлер
1. Алғашқы қадам: командалар тізбегі
2. Конвейер іске қосылды: `for` циклі
3. Түстерді сұрыптау: `if / else`
4. Қанша зат келеді?: `while` және `elif`
5. Робот құрастыру: функциялар (`def`)
6. Бас инженер: айнымалылар
